# enjmin

This is the modern c++ sandbox I use for my C++ masterclasses on optimizing.

It embeds:
- hot reloadable shaders
- imgui
- sfml
- eastl

## Lucas Gibert notes:
Featurs présentes:
- Éditeur ingame: activable avec ctrl + E, save avec ctrl + S
- Save de la map et load
- Death ray: En ligne droite horizontale. Activable avec A
- Homing missile: Pas très magiques toutefois, enfin si, ils sont magiques, il traversent les mûrs!! Activable avec E
- Screenshake: Des tremblements en veux tu en voilà. Aucun empilement à signaler.
- MuzzleFire
- Recul
- Contrôles manettes: Pro controller switch: A missile, B sauter, Y laser et ZR tir principale. Déplacements joystick L. Attention les contrôles varient d'une manette à l'autre.

Manquantes:
- Fée drone
- Prismatic spray
